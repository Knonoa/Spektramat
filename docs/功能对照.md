# 功能对照：SpektraLabAndroid 2.0 与 Spektramat

2026-11-11 逐项核对。左边是 `SpektraLabAndroid`（README、四个页面的 `web/js/screens/*.js` 和对应的 ViewModel）里实际有的功能，
右边是 Spektramat 现在的状态。「已有」表示代码写了并且在模拟器上走通过；没有真机或真相机验证的，单独写明。

## 监视器（USB 联机）

| 2.0 的功能 | Spektramat |
| --- | --- |
| Sony USB（PTP）连接、USB 授权、设备插拔刷新 | 已有。协议代码移植自 2.0（`tether/Ptp.kt`、`Sony.kt`）。**没有接过真相机**，见文末 |
| 实时取景 | 已有 |
| 相机参数回读（ISO / 光圈 / 快门） | 已有，显示在画面下方 |
| 480p / 720p 监看 | 已有 |
| 胶片监看（套胶片色彩，不含颗粒和光晕） | 已有，用的是和暗房同一份胶片表，不再是 17³ 色彩表 |
| 监看色彩：用冲印室当前设置或配方 | 已有：选胶片，或套用配方 |
| 监看录制成 MP4，可把参数烧进画面 | 已有，存进相册 `Movies/Spektramat` |
| 接收相机拍的原片（ARW / JPEG / HIF），先落盘再登记 | 已有。原片进片库「联机 日期」一卷；片库读不了的文件转存 `Download/Spektramat`，不丢 |
| 同时复制一份到手机存储 | 已有（开关，默认关） |
| 必须先选项目，原片按项目归档 | 改了：不用先选项目，直接进当天的联机卷 |
| 信号中断显示最后一帧（2.0 里标注未生效） | 已有，并标明「这是最后一帧」 |
| 恢复联机暂存文件（设置里手动点） | 改成自动：下次启动时把没登记完的原片和录像补上 |
| 遥控快门（2.0 标为未实现） | 新增，**未在真相机上验证** |
| 相机设置写入（2.0 标为未实现） | 没有 |
| 断开后回到别的页面继续收片 | 新增：连接属于 App，不属于页面 |

| 画幅 4:3 / 3:2 / 5:4 / 1:1 / 16:9 / 65:24，保留完整原片 | 已有：取景里把裁掉的部分压暗，原片完整入库，画幅记在这张照片的设置里 |

## 冲印室

| 2.0 的功能 | Spektramat |
| --- | --- |
| 从相册 / 文件 / 分享导入 | 已有 |

| 胶片：型号、配方、曝光、画幅（片幅） | 已有。片幅 11 种，决定颗粒和光晕的尺度 |
| 自动曝光开关 | 没有开关：导入时测光一次，曝光滑杆在它上面加减 |
| 印相：直接扫描底片、相纸、印放曝光、Y / M 滤镜 | 已有 |
| 质感：颗粒、光晕、DIR 耦合、眩光 | 已有 |
| 质感：乳剂散射单独调、扫描锐化开关 | 没有（散射跟着光晕走，锐化常开） |
| **片边**：10 种片幅、整条 / 窄边、6 种片门、齿孔透光 / 黑底、帧号、灰雾、漏光、换机身、印快门与光圈 | 已有，全部。片幅在片边面板里直接选（和胶片工序里的片幅是同一个设置） |

| **日期后背**：液晶 / 点阵 / 仅数据、年月日顺序、画面内 / 帧间、四个角、字号、亮度、同时印拍摄数据、手动改日期 | 已有，全部 |

| 撤销 / 重做、长按看原片、放大 | 已有 |
| 配方：保存、套用、重命名、删除 | 已有保存、套用、删除；重名即覆盖，没有单独的重命名 |
| 导出 2048 / 3072 / 4096 / 完整尺寸 | 已有 |
| 批量冲洗：多选、固定配方、选尺寸、队列、暂停、重试 | 部分：片库多选后可「套用配方」和「冲印」，进后台队列逐张做，可单张停止。队列不落盘，重启后不续 |
| 项目文件夹、按来源筛选 | 没有：用「卷」分组（导入、相机、联机各自成卷） |
| 整饰：曲线、混色、色彩分级、暗角（2.0 没有） | 新增 |

## 没有验证过的部分

- **监视器没有接过真相机。** PTP 的收发和 Sony 数据的解析有 13 个单元测试（分包、空包、截断、越限、错误码），
  App 里的流程（取景、胶片监看、收片、录制）用调试版的「演示相机」走通过。连接握手、属性码、取景对象号都照搬 2.0；
  遥控快门是新写的（按 libgphoto2 的半按 `0xD2C1` / 全按 `0xD2C2`），在真机上可能不被接受，那时界面会提示并且不影响在相机上按快门。
- 相机的闪光灯、系统相机回传、拍下即冲印：代码已写，模拟器没有闪光灯，这三项没有实测。
- 玻璃放大镜只在 Android 16 模拟器（软件渲染）上看过。
