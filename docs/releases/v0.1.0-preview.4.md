# Spektramat v0.1.0-preview.4

## 中文

- **相机先存原片，再后台冲印。** 未加滤镜的相机原片会先进入「Spektramat Originals」，JPEG 成片随后单独保存到「Spektramat」。可以继续拍摄，也可以离开相机页面。冲印队列支持恢复未完成的订单，并核对相册发布状态以避免重复。
- **按设备调整导出资源。** 根据 CPU、内存、温度、省电模式以及前后台状态调整渲染线程。最终照片仍读取原文件并执行完整算法；预览代理和 LUT 不参与成片渲染。
- **工作台创意工具。** 新增柔焦、炫光、辉光以及最多五张照片的多重曝光，支持叠加层构图与渐变蒙版。胶片型号可关闭效果预览，改看胶卷示意图。高光警告可独立开关。
- **整卷与交付。** 多张照片可合成连续横卷、纵卷或按每行张数自动换行的胶片袋。项目支持入选标记、编号接触印样与批量冲印，Sony USB 监看支持自动重连。
- **手机照片与操作。** 支持兼容设备上的 SDR HEIC／HEIF、AVIF，以及 Android Motion Photo 的实况播放和静态封面冲印。iPhone Live Photo 暂只处理静态封面，不配对 MOV。新增默认进入页设置；工作台右下角移除按钮经确认后只移出工作台。

实测：59 项 JVM 单元测试、85 项模拟器测试通过。OnePlus 7 Pro 开启「允许完全后台行为」后，验证 JPEG 原片先入库，息屏后完整分辨率成片入库。部分手机需在「设置 → 冲印 → 后台冲印」允许后台运行。Sony USB 联机交付仅验证了模拟流程。

APK：`com.spektra.latent.dev`，版本 `0.1.0-preview.4-dev`，版本代码 4，Android 8.0+，arm64-v8a／x86_64。沿用 Preview 3 的签名，可以覆盖更新并保留数据。

## English

- **Save the camera original first.** The unfiltered capture goes to the Spektramat Originals album before its JPEG print is saved separately to Spektramat. Keep shooting or leave the camera while the print runs. The queue can resume unfinished orders and checks gallery publication to avoid duplicates.
- **Device-aware export.** Render threads adapt to available cores and memory, temperature, battery saver and whether the app is visible. Final photos still use the full engine and original files, independent of preview proxies and LUTs.
- **Creative workbench.** Add soft focus, flare and glow; compose up to five exposures with layer positioning and gradient masks. Turn off film-stock previews to show cartridge illustrations. Highlight warnings are optional.
- **Film rolls and delivery.** Combine images into a continuous horizontal or vertical strip, or set the row length for a film sleeve layout. Mark project selects, generate numbered contact sheets and batch-print. Sony USB tethering supports automatic reconnection.
- **Phone formats and controls.** Import SDR HEIC/HEIF and AVIF on compatible devices, play supported Android Motion Photos, and print their still frames. iPhone Live Photo support covers the still only. Choose the start screen and confirm before removing a photo from the workbench.

Validation: 59 JVM tests and 85 emulator tests passed. A OnePlus 7 Pro saved the JPEG original first and finished a full-resolution print with the screen off after unrestricted background battery use was enabled. Some phones require this setting under Settings → Printing → Background printing. Sony USB delivery was tested with a simulated workflow.

APK: `com.spektra.latent.dev`, version `0.1.0-preview.4-dev`, version code 4, Android 8.0+, arm64-v8a/x86_64. Uses the Preview 3 signing key for in-place upgrades.
