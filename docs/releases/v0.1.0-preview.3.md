# Spektramat v0.1.0-preview.3

## 中文

- 工作台使用共享 float32 线性代理与 GPU LUT 快速预览；胶片／相纸候选图缩小至 128 像素，内置 68 个默认预览 LUT。交互预览最长边 720 像素，稳定后提高至 1280，并可生成完整算法校样。
- 照片导出重新打开全尺寸原片，执行完整胶片、印相与扫描算法后再缩放和编码；代理和预览 LUT 不参与最终照片导出。
- 白位提供“原始白位”和“完整扩展”。完整扩展按材料参考白标定，不按画面最亮像素自动归一化；旧配方保持兼容。
- 默认 JPEG，可选 16 位无损 PNG 和 32 位浮点线性 DNG，移除“自动”和 TIFF 输出。PNG 嵌入匹配输出色域／编码的 ICC；DNG 保留负值与超白数据，包含完成的胶片效果，不是相机传感器 RAW。输入 TIFF 仍受支持。
- 改进相册发布：先完整编码并原子保存，再发布到相册；相册拒绝时保留应用内成片并可分享。JPEG 是默认相册分享格式。
- 导出动画随后台任务保存，离开工作台后返回可继续显示。观片台点击导出直接保存虚线范围内的全部照片，无需再次选择导出范围。

验证：52 项 JVM 单元测试、19 项针对性 Android 检查分别通过；18 项原生栅格精度检查及 RAW 浮点精度检查通过。DNG 经独立 LibRaw 解码器识别，独立解压及应用重读检查保留负值和超白样本。上述检查不代表所有手机、图库或 RAW 格式均已验证；真机帧率与延迟尚未测量。

预览 APK 使用 debug 签名，包名 `com.spektra.latent.dev`，应用内版本 `0.1.0-preview.3-dev`，版本代码 `3`。支持 Android 8.0+，包含 arm64-v8a / x86_64。与前版签名一致时可覆盖安装并保留数据。DNG 的相册展示取决于查看器支持，其他软件也可能额外应用曝光或色调映射。JPEG／PNG 仅在最终编码时限制到文件可表达的位深和范围；DNG 保留浮点范围。

## English

- Faster workbench editing with shared float32 linear proxies and GPU LUT previews. Film/paper samples use a 128-pixel long edge, with 68 bundled default preview LUTs. Interactive previews use 720 pixels, refine to 1280 pixels and can produce a full-engine proof.
- Photo export reopens the full-resolution original and runs the complete film, print and scan algorithm before resizing and encoding. Proxy images and preview LUTs are excluded from final photo export.
- Added Original and Full Extension white-point modes. Full Extension uses the material reference white rather than normalizing to the brightest image pixel; existing recipes remain compatible.
- JPEG is now the default, with 16-bit lossless PNG and 32-bit floating-point linear DNG alternatives. Auto and TIFF output options were removed; TIFF input remains supported. PNG carries a matching output-space/encoding ICC profile. DNG preserves negative and above-white samples and contains the finished film effect, rather than sensor RAW data.
- Improved gallery publication with complete encoding and atomic local storage before publishing. If the gallery refuses a file, the app keeps a shareable local print. JPEG is the default gallery-friendly format.
- Export animations remain attached to the background job and resume after returning to the workbench. Light Table export directly saves all photographs within the dashed export bounds.

Validation: 52 JVM tests and 19 focused Android checks passed across targeted runs. All 18 native raster precision cases and the RAW floating-point precision check passed. An independent LibRaw decoder recognized the DNG; independent decompression and in-app rereading retained negative and above-white samples. These results do not establish compatibility with every phone, gallery or RAW format. Physical-device frame rate and latency have not been measured.

This is a debug-signed preview: `com.spektra.latent.dev`, version `0.1.0-preview.3-dev`, version code `3`, Android 8.0+, arm64-v8a/x86_64. Matching signatures allow an in-place update that retains app data. DNG gallery visibility depends on viewer support; external software may apply additional exposure or tone mapping. JPEG/PNG constrain precision and range only at final encoding; DNG retains floating-point range.
