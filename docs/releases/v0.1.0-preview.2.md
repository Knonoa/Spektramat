# Spektramat v0.1.0-preview.2

## 中文

- 新增 GitHub 在线更新：侧边栏「设置」下方「检查更新」，支持版本提醒、发布说明、APK 下载进度、取消下载与系统安装。
- 修复白棚和高调照片进入工作台后被二次自动曝光压暗。已拍照片固定原片曝光基准，关闭自动测光和印相曝光补偿，手动曝光直接影响成片。
- 工作台使用低分辨率代理预览，导出重新读取全尺寸原片并运行完整 spektrafilm 照片引擎。小尺寸输出也先渲染原片再缩小。
- 支持 JPEG、8/16 位 PNG、TIFF 整数／float32 的原生精度解码与 ICC 浮点转换。RAW 的黑电平、去马赛克、白平衡、镜头增益和色彩矩阵改为 float32，保留负值及超白；移除输入提前裁切与自动亮部去饱和。
- 默认保存带 ICC 的 32 位浮点 TIFF；8 位 JPEG 是用户显式选择的分享格式。无可靠保精度解码器或仅能提供 RAW 内嵌预览时，拒绝原片导出。

验证：45 项 JVM 单元测试、17 项模拟器照片／曝光／GPU 测试、18 个原生 raster 精度案例通过；float、照片入口和 GPU 预览合同检查通过。Sony A7M3 / A7M4 ARW 以及 synthetic 负值、超白和相邻采样值检查通过。V2454DA 本轮覆盖安装被系统拒绝，此版本尚未完成真机验证。

预览 APK 使用 debug 签名，包名 `com.spektra.latent.dev`，应用内版本 `0.1.0-preview.2-dev`，Android 8.0+，包含 arm64-v8a / x86_64。需与上一预览版签名一致才能覆盖。HEIF/AVIF、X-Trans、部分四通道／特殊传感器布局暂不支持完整保精度导出；软件无法恢复传感器或原文件已丢失的数据。

## English

- Added GitHub release checks below Settings in the sidebar, with in-app reminders, release notes, APK download progress, cancellation and Android installation.
- Disabled automatic metering and print-exposure compensation for saved photos, preserving the original exposure baseline and making manual EV changes visible.
- Workbench previews use proxies. Export reopens the full-resolution original and runs the complete photo engine, resizing only after rendering.
- Added native-precision PNG/TIFF and float ICC conversion. RAW black subtraction, MHC demosaic, white balance, lens gains and camera conversion now run in float32 without premature shadow/highlight clipping or automatic highlight desaturation.
- Default export is ICC-tagged float32 TIFF; 8-bit JPEG is an explicit sharing option. Unsupported precision-preserving formats and embedded-preview-only RAWs cannot masquerade as original exports.

Validation: 45 JVM tests, 17 emulator photo/exposure/GPU tests, 18 native raster precision cases and host float/photo-route/preview checks passed. Sony A7M3/A7M4 ARW and synthetic extended-range/adjacent-sample checks passed. Physical-device installation was rejected by the V2454DA system; this revision still needs physical-device validation.

This is a debug-signed preview (`com.spektra.latent.dev`, `0.1.0-preview.2-dev`), Android 8.0+, arm64-v8a/x86_64. Unsupported sensor layouts are explicitly refused. Future APK update installation still needs end-to-end verification.
