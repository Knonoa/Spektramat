# 颗粒与眩光随机模型对齐

基准为 spektrafilm `3bb2c2d2801ff68b92019cf1dbcbb133d60832bc`。

## 修改

照片颗粒的 Poisson / Binomial 采样已改为标准库完整概率分布。旧实现对高均值 Poisson 和高方差 Binomial 使用正态近似，与 reference 默认 `use_fast_stats=false` 的 SciPy 分布不同，尤其会改变偏度及尾部。分层、单层、`n_sub_layers`、粒子面积、uniformity、染料云模糊、微结构和最终 blur 沿用已经移植的 reference 公式。

核对 `develop.py` 后确认：它把归一化的密度曲线传给 `apply_grain()`，因此单层颗粒使用 `dmax_norm` 正确，不应改用未归一化的 `dmax_raw`。

glare 与 microstructure 的 lognormal 参数按线性域 mean/std 转为底层 normal 参数。glare 在 XYZ 域、black/white correction 后加入，仅用于相纸扫描。

## 可复现验证

```powershell
pwsh -NoProfile -File tools/host/run_stochastic.ps1
```

该脚本直接调用生产 C++ grain / scan kernel，并与未修改的 Python `apply_grain()` / `compute_random_glare_amount()` 比较。结果保存在 `build/stochastic-parity/results.json`。

- 6 组 grain：Portra 分层、Portra 单层、Portra 单层 n=4、Ektachrome 分层、HP5 分层、Portra 微结构。每组 512×512、4 个密度区块、3 个通道；相同 C++ seed 重跑逐像素一致。
- 7 组采样器：Poisson λ=0.3/35/1000，Binomial (n,p)=(20,0.2)/(100,0.3)/(1000,0.98)，lognormal mean=0.03/std=0.021；每组 300,000 样本，对照 SciPy 理论 CDF。
- 2 组 glare：默认参数和 percent=0.08/roughness=1.2/blur=2，从实际 scan 输出中提取添加的白光量。

全部通过，`STOCHASTIC_PARITY_FAILURES 0`。本轮 grain 的区块方差比为 0.9562–1.0519，采样器理论 CDF 最大偏差 0.00202，glare 方差比分别为 1.0195、1.0343。

验收同时约束均值、方差、CDF。均值门槛考虑 blur 引入的相关采样；CDF 比较为 float32/float64 的原子概率质量保留 `max(1e-5,0.002σ)` 密度容差。分层常规案例使用 5 µm 像素和 stock 染料云参数；微结构专项使用 0.25 µm 像素并关闭染料云 blur，以分别观测两个效应。

## 一致性的边界

这里证明已测参数的概率模型和纹理统计一致，不声称随机图案逐像素等于 NumPy/Numba。C++ 使用按 seed/stream/row 拆分的本地随机流，以稳定照片重冲印及多线程结果；不同 C++ 标准库的分布实现也可能产生不同样本。产品额外的 `grain_amount` 混合仍保留，值为 1 时等价于 reference grain 输出。Android GPU 视频 preset 关闭颗粒和 glare，它们不能由静态 3D LUT 表达。
