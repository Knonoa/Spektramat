# 高光检查、冲印队列与联机交付

## 高光警告

默认关闭。可在「设置 → 冲印 → 高光警告」或工作台的太阳图标开关。它只读数据，不自动调整曝光、白位或照片。调节页仍显示原图及基础校正；警告覆盖层只在胶片效果的精确校样上显示。

- 黄色条纹：某个 RGB 通道在线性光中达到参考白位的 95%，但未超过参考白；DNG 的超白像素同样用黄色提示。
- 红色条纹：某个输出通道超过归一化白位，JPEG 或 PNG 不能编码这部分数值。JPEG 按 sRGB 输出检查，PNG 按所选输出色域检查。浮点 DNG 保留超白值。
- 校样为代理分辨率，排除片边和日期区域；冲印队列则按请求尺寸在最终编码前重算。因此，校样与导出报告的区域比例可能略有差异。警告是输出检查，不能用来判断相机传感器是否过曝。

## 冲印队列

侧栏打开「冲印队列」。工作台、相机和项目的原片冲印进入同一队列，按顺序执行，逐张显示阶段、失败原因、文件格式及保存位置。可取消等待或正在处理的任务，重试使用原订单的参数。成功后可分享单张；项目批次处理完后可分享其中已成功保存的文件。

离开工作台或息屏后，队列由 Android 前台服务继续运行。若系统中断服务，重新打开应用会尝试恢复未完成的订单并检查是否已发布；无法安全判断的旧订单会提示先核对相册。部分手机需在「设置 → 冲印 → 后台冲印」打开系统设置并允许后台运行。取消与保存同时发生时，已经发布的文件保留为成功；清除记录也不会删除保存过的照片。

## 多重曝光构图

工作台「创意 → 多重曝光」中，打开对应叠加层的「构图」。可在照片上拖动、双指缩放及旋转，或用刻度精调。可加渐变蒙版，调整方向、中心和羽化；蒙版保持在底图画幅上。底图与叠加图共最多五张。叠加范围之外由底图和其他叠加层显示，没有边缘拉伸。旧项目保持居中填满的默认位置，修改可撤销重做。交互使用代理文件，成片及接触印样重新解码原片进行浮点合成。

## 联机拍摄与交付

1. 在监视器选择项目，再从「监看色彩」选择配方。收到的照片带着拍摄时的配方归档，原文件不改写。
2. 点监视器下方最近收到的照片查看校样并标记入选。项目页也可长按多选后标记，或筛选已有入选照片。
3. 在项目点「交付」。可生成编号 JPEG 接触印样（按片号排序，每页最多 24 张），也可把入选照片批量冲印为 JPEG、PNG 或 DNG，并在队列中分享。
4. Sony USB 会话意外中断时，若同一台设备仍接入且权限仍在，可自动重试两次。此行为可在监看设置关闭。拔线、相机身份变化或权限失效时由用户重新连接。
