# 算法对齐实现与验证记录

本记录保存照片完整算法对齐的验证基线。后续手机相机取景已改为 GPU LUT 实时预览，视频录制继续使用独立 LUT；拍下的照片、缩略图、暗房和导出仍使用完整算法。取景改动及本轮验证见 [GPU 实时预览记录](相机GPU实时预览-2026-11-12.zh-CN.md)。

- SpektraLab：`1952c63537ec576d24422f1065b12495631346a5`，提供相同的 25 款胶片、9 款相纸和中性滤镜数据库。

- manifest 记录生成器、profile loader、profiles、波长轴、CMF、中性滤镜及光谱输入数据的哈希。启动时验证资产和参考版本。

Python oracle 只把 profile loader 和中性滤镜数据库指向相同的 SpektraLab 产品资产；算法仍运行固定版本 spektrafilm，避免把产品 profile 差别混入算法误差。

## 照片管线

`PHOTO_FULL` 与 `PHOTO_PREVIEW_FULL` 均执行完整算法；照片样张预览只缩小源尺寸并异步处理。拍照入库、文件导入、片库缩略图、暗房样张、重新冲印、导出、Sony 收片及非录制监看均调用 `FilmEngine.develop()`。手机拍摄前取景另走 GPU LUT，不属于 `PHOTO_PREVIEW_FULL`。照片明确关闭印相/扫描 3D LUT；旧 `renderFast()` 标记为编译错误级别弃用。

当前管线包括：

1. 源 ICC 转换为 extended linear sRGB；保留 F16 输入负值和超白值。
2. Hanatos2025/Mallett2019、UV/IR、adaptation window/surface、spectral Gaussian blur、xy/Oklch input gamut。
3. 七种自动曝光、手动 EV、boost/protect、相机 diffusion/lens blur、scatter/halation。
4. density curve gamma、DIR matrix/inhibition/diffusion/tail、分层/单层 grain 和微结构。
5. 81 波长精确印相、数据库中性滤镜、曝光归一化与 compensation、preflash、放大机 diffusion、相纸 morph。
6. 81 波长精确扫描、black/white/midgray reference correction、glare、输出 gamut、scanner blur/unsharp 与 CCTF。
7. 保留 App 的场景调整、整饰、片边和日期扩展；reference parity 使用中性的场景调整与整饰。

Hanatos TC 表和 perceptual gamut 边界表是参考算法本身的数据结构，不是照片胶片→印相→扫描的简化 LUT。

参数由版本化 PhotoModel v2 的 137 个数值字段与输出空间名称传入 JNI，并随配方保存。固定版本参考虽声明 `enlarger.lens_blur`，但 PrintingStage 没有执行该参数；本次保持此行为。相机 lens blur、放大机 diffusion、扫描 lens blur 则实际执行。

`photoGrade()` 不预乘曝光。引擎对当前输入测光，再应用手动 EV 一次；`Frame.meteredEv` 只作元数据。print compensation 默认 true，只接收手动 EV。`exposure_preapplied` 兼容分支有独立契约测试，不是照片默认路径。

PROOF negative cache 使用源 float 字节、grade、胶片参数、seed 和几何信息；印相侧编辑复用负片，改变源或胶片参数则失效。

暗房和批量冲印提供自动、JPEG、浮点 TIFF 选择。JPEG 经色彩管理转换为 sRGB；显式 TIFF 直接请求 native F16 成片，保留配方输出空间与 CCTF，并嵌入匹配的 ICC。缩略图、观片台代理图和成片显示副本转换为 sRGB，避免将线性样本直接当作显示编码。TIFF 不交给不支持其格式的 ExifInterface 重写。

## 随机模型

Poisson/Binomial 使用完整概率分布，移除高均值正态近似；glare 与微结构的 lognormal 由线性域 mean/std 构建。参考 develop() 传入归一化曲线，因此 grain 使用 `dmax_norm`。

`tools/host/run_stochastic.ps1` 的 6 组 grain、7 组采样器和 2 组 glare 全部通过。检查均值、方差、CDF 和同一 C++ seed 本地重现。grain 区块方差比 0.9562–1.0519，采样器理论 CDF 最大偏差 0.00202。详情见 [随机模型记录](颗粒与眩光随机模型验证-2026-11-12.zh-CN.md)。

C++ 随机流不同于 NumPy/Numba，不承诺随机图案逐像素相同，也不承诺不同 C++ 标准库间样本一致。产品 `grain_amount` 混合仍保留，默认 1 对应参考输出。

## 支持范围与剩余验收

- 输出支持 sRGB、Display P3、Adobe RGB (1998)、ProPhoto RGB；未实现 colour 库任意自定义空间入口。
- 放大机资产目前支持 TH-KG3、D55、D50、T、K75P；任意黑体温度/全部标准光源未开放。
- 高级参数经 PhotoModel/配方/JNI 接入，普通界面未逐项新增控件。
- 浮点 TIFF 保留输出空间、CCTF 和 ICC，文件使用 float32 样本；样本来自 Android F16 成片，不能视为全 float32 精度导出。
- 暗房等照片样张使用相同运算，受源分辨率影响；手机实时取景使用 GPU LUT 近似，光晕、颗粒等效果以成片为准。
- 视频的空间、随机、全局统计效果按固定 preset 关闭。见 [视频实现记录](视频LUT实现与验证-2026-11-12.zh-CN.md)。
- 硬件拍摄、真实 RAW/USB 相机、编码录制稳定性、手机性能与峰值内存需要真机验收。
- 已测误差范围不能表述为所有输入、全部参数组合或随机样本的数学恒等。
