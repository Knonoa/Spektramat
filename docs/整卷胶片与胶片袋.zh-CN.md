# 整卷胶片与胶片袋

- 入口：「冲印室 → 项目」选中 2–36 张照片，再点上方胶片图标；也可在观片台点胶片图标，从台上的照片选片。
- 默认按拍摄时间装卷，可拖动把手或用箭头换序，点任意一格可独立缩放、移动裁切，移出作品不删除原片。
- 「横向整卷」「纵向整卷」采用连续齿孔和片号，只有一组片头片尾。「胶片袋」可指定每行格数，自动换行，保留行间袋位和末行留空。
- 「整卷定调」默认采用第一格的配方，保留每张照片的基础校正；可选已存配方，或保留各格调色。作品统一使用 135 片幅和卷边。
- 预览使用低分辨率浮点代理。导出作为单条冲印任务，逐张读取原片、用完整照片管线渲染，再进行裁切缩放和排版。可选 JPEG 或 16 位 PNG，统一为 sRGB。整卷最多 12000 像素长边、800 万像素，不拆成多文件。
- 全局高光检查开启时，队列会显示照片区域的合计统计；队列支持取消、重试、分享，任务不会因离开编辑器而中止。
