## 算法保持

- 拍照所得 JPEG/RAW、导入照片、照片缩略图、暗房样张及最终冲印继续调用完整 `FilmEngine.develop()`。
- 手机相机实时取景继续使用 GPU `PreviewLut` 管线。
- 视频继续使用独立的、包含完整胶片转换的 `VideoLut`。
- 胶片和相纸选项中的样张由真实引擎生成，未采用 H5 的 CSS 示意滤镜代替照片处理。
- 本轮原生引擎扩展仅提供只读画面区域和日期字模边界，供直方图布局避让使用，没有修改胶片成像计算。

直方图来自实际显示的样张或原片，按 sRGB 8 位、每通道 256 档统计；其数值描述当前显示图像，不作为浮点导出的曝光测量值。

## 设计表现与验收边界

- 普通玻璃组件使用半透明、渐变和边缘高光；侧栏、暗房及弹层使用背景模糊。没有复制 Chromium SVG 的边缘光学折射效果。
- 未实现设计中的实验接触印相页面。
- 冲印动画使用原片和真实样张编排，不显示引擎的中间底片数据。
- 真机硬件拍照和 USB 相机连接仍需实机验收。API 31 模拟器的 `EmulatedFakeCam` 在 JPEG 编码时发生原生 SIGSEGV，导致 ImageCapture 关闭；项目原有 `CameraPhotoRouteTest` 已记录该模拟器限制。自动化测试使用同一 JPEG 输入验证后续照片处理与保存流程，不能替代真实相机端到端拍摄。

```powershell
adb install -r .\dist\Spektramat-ui-20261113-debug.apk
```

同目录 `.sha256` 文件用于检查安装包传输是否完整。
