# 工作台快速预览与原图导出实施记录

日期：2026-11-16。修改基线：`91c62f9`。

## 实际处理流程

原始文件按字节保存，编辑参数单独入库。工作台和选片列表共享未套效果的线性 RGB float32 源代理，默认最长边 1280，低内存设备为 960。代理具有内存 LRU、带校验和的浮点磁盘缓存；缓存损坏后从原始文件重建。改变曝光、胶片和相纸不会重新解码源图；裁切、镜头校正或原始文件变化会更新源代理。

- 胶片／相纸候选图：最长边 128，使用完整照片引擎采样生成的 33³ LUT。
- 内置 68 个默认 33³ LUT，覆盖 25 款胶片的常见组合及两档白位。引擎／shaper 版本、完整参数及文件 SHA-256 匹配才加载；自定义配方未命中时在后台生成并缓存。可用 `tools/host/bake_photo_previews.ps1` 重建，派生素材继续遵守 CC BY-SA 4.0。
- 工作台交互：最长边 720 的 GPU 快速预览；提交调整后提高至 1280。已有 65³ LUT 时复用，普通曝光、白平衡、整饰不重烘焙颜色转换。
- 完整校样：停手约 650 毫秒且没有选片或导出活动时，在最长边 960 的代理上执行完整算法；也可点击预览状态主动请求。颗粒、光晕、片边、日期等以完整校样和导出为准。
- “调节”页：使用同一源代理进行原图校正，绕过胶片模拟。
- 原图对比、缩放和平移：只改变显示，不重新解码、烘焙或处理照片。
- 照片导出：重新打开原始文件，以原生尺寸执行完整算法并产生 float32 成片，然后按用户选择缩小和编码。观片台拼版中的每张照片也先从原始文件完整处理。

LUT 是显示用近似，不是照片导出算法。带符号 HDR shaper 保留负输入，超域采用边界外推；屏幕显示范围不改变源代理和原图数据。导入照片保持关闭场景自动曝光与印相曝光补偿；手动 EV 仅应用一次。

自定义输出色域参与 LUT 缓存身份：按所选 sRGB、Display P3、Adobe RGB 或 ProPhoto RGB 执行完整输出色域／亮度映射，整饰后再转换为屏幕 sRGB。GPU 和 CPU 后备路径共用显示转换矩阵，避免用默认 sRGB LUT 覆盖宽色域配方。

## 白位

默认“原始白位”保留胶片／相纸原始纸白，未硬编码为某个 210 多的数值。“完整扩展”按材料参考黑白标定，并在输出色域／亮度映射后把材料参考白亮度扩展至 1.0；不按画面最亮像素做自动归一化。有限负值和高于白点的浮点值保留。

旧配方的自定义白位保持兼容，直到用户明确选择新挡位。参数格式升级到 schema 3，继续接受 schema 1 和 2。处理保持 float32，屏幕为显示转换。当前导出为 JPEG（默认）、16 位 PNG 或 32 位浮点线性 DNG，已移除自动和 TIFF 导出选项；JPEG／PNG 仅在编码边界限制到对应文件位深和范围，DNG 保留浮点范围。

## 导出可靠性

先编码为应用管理的临时文件，关闭并同步成功后原子发布本地文件，再复制同一份字节到相册。文件名含唯一标识，重复导出不覆盖。检查相册发布返回值；拒绝插入、写入或发布时，保留完整且可分享的应用内文件。编码失败和取消清理半文件；成功发布后的取消保留成片。成片保存成功后，目录登记失败单独记录，不误报成片丢失。

## 本次修订：相册与任务恢复

默认改为 JPEG，并提供 PNG 和 DNG。JPEG 使用 sRGB 8 位；PNG 使用 16 位无损编码并嵌入匹配输出色域／编码的 ICC；DNG 是已完成胶片转换的线性浮点成片，不是相机传感器 RAW。Android 10 及以上发布到 Pictures/Spektramat，DNG 的相册展示由查看器支持决定；相册拒绝时明确提示保留在应用内并可分享。

导出动画时间线及完成确认随应用级后台任务保留，工作台重新进入时按照片重新附着；已经保存的成片不会因页面退出而丢失。
