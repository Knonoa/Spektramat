# 创意功能与胶片列表预览

工作台新增“创意”页：柔焦、炫光、辉光和多重曝光。所有效果默认关闭。

- 柔焦保留清晰核心，混合柔化后的画面。
- 炫光从真实亮部产生宽域散射和镜头光斑。
- 辉光让亮部柔和扩散，与胶片算法中的光晕独立调节。
- 多重曝光包含当前底图，最多 5 张。可调每张权重，移除或清除叠加，可撤销与重做。不同画幅居中填满底图，保持比例。

多重曝光按线性光的权重平均合成，避免简单相加导致照片数量越多越过曝。叠加层为导入原文件的逐字节副本；应用不改写相册原图。移除叠加只改变合成关系。配方可以保存创意效果强度，但不会把私人照片引用带到其他图片。

处理顺序：原片解码 → 多重曝光 → 柔焦／炫光／辉光 → 原有场景调节 → 胶片及相纸转换 → 原有整饰、片边与日期。

交互使用低分辨率 float32 代理和现有 GPU LUT。普通场景或胶片调整复用已合成的代理；完整校样和原片导出使用同一套创意算法。导出重新读取各张原图，逐张合成后再运行完整胶片管线，不用预览位图代替原图。新增创意模块不截断浮点高光或负值；最终显示、JPEG／PNG 编码仍按所选格式输出。

“调节”页继续按原有约定显示原图调节；“创意”及后续页显示包含创意与胶片转换的结果。原图对比保留导入底图。

胶片型号列表新增持久化“效果预览”开关，默认开启。关闭后改用按型号绘制的原创胶卷插图，不创建候选预览渲染器、不请求候选 LUT 或照片代理；选择胶片仍会更新工作台主画面。拍照、联机页面的列表保持原有行为。
