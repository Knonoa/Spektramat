# GitHub 在线更新

侧边栏「设置」下方新增「检查更新」。页面展示当前版本、检查结果、新版说明、APK 大小、下载进度及安装按钮。

应用从公开的 `Knonoa/Spektramat` GitHub Releases API 获取已发布版本，不使用令牌。使用 Release 列表是为了识别预览版本，因为 GitHub 的 `/releases/latest` 排除预发布。版本按语义版本比较，忽略当前 debug 构建的 `-dev` 后缀；预览安装可接收后续预览和正式版本。

自动检查有 6 小时频率限制，手动检查可立即重试。新版本显示侧边栏标记及应用内提醒，同一版本的提醒关闭后不重复弹出。网络异常、GitHub 限流、取消下载、校验失败会在页面说明。

APK 下载到应用缓存。校验顺序为 GitHub asset 的 SHA-256 digest，或对应 `.apk.sha256` / `SHA256SUMS.txt` 文件中的精确文件名。缺少校验值时不安装。下载后校验应用 ID、递增的 Android versionCode 和签名，避免跨渠道安装或降级。安装交由 Android 系统确认；未授权安装来源时打开该应用的系统设置，返回后可再次点击安装。

每次发布需递增 `versionCode`，使用相同包名与签名，并提供 APK 及 SHA-256。当前预览渠道为 `com.spektra.latent.dev`，正式包 `com.spektra.latent` 无法覆盖该渠道。更新保留应用私有片库；卸载则仍会删除私有数据。

本轮验证：版本比较、预览版筛选、checksum 文件匹配单元测试通过；模拟器实际访问 GitHub 并正确显示当前版本已最新，侧边栏及横竖屏页面已检查。未来新版 APK 的完整系统覆盖安装尚需端到端验收。
