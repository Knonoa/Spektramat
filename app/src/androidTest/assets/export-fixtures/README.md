# Native export fixtures

Generated by `tools/host/run_raster.ps1` from synthetic data; no third-party photographs.

- `rgb16.png`: adjacent 16-bit sRGB codes, generated as `srgb16.png`.
- `rgb16.tif`: adjacent 16-bit RGB codes, generated as `test2.tif`.
- `linear-float.tif`: signed/above-white float32 RGB plus linear ICC, generated as `test11.tif`.
- `sensor14.dng`: uncompressed synthetic 14-bit Bayer signal in a 16-bit container, generated as `raw-8192.dng`.

`PrinterOriginalTest` uses these to check native-size original export, floating TIFF reread, source-byte integrity and independence from a deliberately tiny source proxy.
