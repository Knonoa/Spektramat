Android distribution changes
---------------------------
The Android asset engine/engine.bin is generated by tools/bake_assets.py
from the reference profile data, spectral constants and neutral print-filter
database. It packs runtime film/paper tables and the hanatos2025 camera LUT
for the Android C++ engine. edge_sensitivity.inc is generated by
tools/bake_edge_sensitivity.py from the same measured spectral sensitivity.
No measured spectral curves were edited to implement film borders or dates.
Film Edge and Date Back expose the negative before development.

These generated profile/LUT encodings remain under CC BY-SA 4.0.
See the linked repository sources and generation scripts for provenance.
