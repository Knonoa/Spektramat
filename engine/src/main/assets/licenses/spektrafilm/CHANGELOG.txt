Android distribution changes
---------------------------
The Android asset engine/engine.bin is generated by tools/bake_assets.py
from the reference profile data, spectral constants and neutral print-filter
database. It packs runtime film/paper tables and the hanatos2025 camera LUT
for the Android C++ engine. edge_sensitivity.inc is generated by
tools/bake_edge_sensitivity.py from the same measured spectral sensitivity.
No measured spectral curves were edited to implement film borders or dates.
Film Edge and Date Back expose the negative before development.

These generated profile/LUT encodings remain under CC BY-SA 4.0.
See the linked repository sources and generation scripts for provenance.

Workbench preview cubes (2026-11-16)
------------------------------------
photo-previews/*.rgb are derived 33-cube float32 preview tables generated by
tools/host/bake_photo_previews.ps1 and bake_photo_previews.cpp, sampling the
Android full pointwise engine with the same engine/engine.bin profile data.
They cover default film/paper combinations with original and expanded
reference-white modes. Spatial and random effects are excluded; full photo
exports do not use these preview tables. manifest.json records the engine
asset hash/version, signed HDR shaper and SHA-256 of each generated table.
These derived preview LUT data remain under CC BY-SA 4.0 with the original
authors and sources credited above. Android preview/white mapping changes
are by the Spektramat contributors: https://github.com/Knonoa/Spektramat.
